# W3_audience / data

| File | What | Source |
|---|---|---|
| `oh_panel_400.parquet` | 400 twins: `twin_id`, `party`, `age_band`, `educ`, `race`, `sex`, `ideology` (0–100, matched respondent's ideology rescaled; 0 = very liberal), `weight` (Ohio voters represented), `persona_text`, `persona_sha256` | Workshop 1 seeded draw, copied by the organisers; the personas are the morning's, unchanged |
| `issues.csv` | `issue`, `item` (the placement item the twins are asked about), `left_label`, `right_label` | The pre-registered study's items (`items_master.csv`) |
| `ads_frozen.csv` | `ad_id`, `issue`, `arm` (targeted/untargeted), `target_position` (20/40/60/80; blank for untargeted), `words`, `text` | Frozen with the OSF registration, 7 Oct 2026; reproduced exactly |
| `real_ads_judges.jsonl` | `ref_id`, `source_ad_id` (Google political-ad archive), `party`, `state`, `office` (blank where not recorded), `topic`, `words`, `text` | ten campaign ads, nine from Ohio and one from Illinois, names removed; selected by Laurenz Guenther |
| `stage_ads.csv` | `ad_id` (`S<stage>_<issue>_<group>`), `issue`, `target` (group), `prompt`, `text`, `words`, `stage` | Stages 1 and 2 and the Stage 3 worked example (`stage` 3), written by `gpt-5-mini-2025-08-07` with the notebook's prompts, generated by the organisers |
| `stage_answers.jsonl` | one line per ad × twin of the 50-twin audience: `ad_id`, `twin_id`, `persona_sha256`, `ptv` 0–10, `model` | same run |
| `stage_judges.jsonl` | one line per ad × judge: `ad_id`, `judge`, `ref_id` (the real ad shown), `real_pos` (A/B), `pick`, `confidence`, `spotted` | same run |
| `ad_answers.jsonl` | one line per twin × script: `answer_id` (`twin_id|ad_id`), `place` 0–100, `agree` 0–100, `convincing` 1–7, `ptv` 0–10, `model`, `persona_sha256`, `run_started_utc`, tokens | generated by the organisers, `gpt-5-mini-2025-08-07`, reasoning effort low, one replicate, with the earlier first-person, four-question interview; Section 3 uses `ptv` only |

Nothing here is a real person's advertisement rating. The twins' personas carry
"not observed" for registration and turnout history, as in Workshop 1, and the
study's scripts name no candidate, party, state or office. The real ads are public
campaign ads, with candidates' names removed.
